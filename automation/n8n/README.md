# ربط رادار المنافسات بـ n8n — المرحلة الأولى

هذه المرحلة تستقبل نتيجة المزامنة من الرادار بعد انتهاء فحص اعتماد، ثم:

1. تتحقق من عقد البيانات ومصدره.
2. تزيل التكرار داخل الحمولة بالرقم المرجعي.
3. تتجاهل تشغيل المزامنة إذا وصل `syncId` نفسه مرة أخرى.
4. تحفظ بصمة الحقول الأساسية لكل منافسة داخل بيانات Workflow في n8n.
5. تسجل آخر 500 تشغيل وآخر 200 معرّف مزامنة.
6. تعيد إلى الرادار تنبيهًا بعدد المنافسات الجديدة والمتغيرة.

## حدود أمنية

- لا يُرسل اسم مستخدم اعتماد أو كلمة المرور أو رمز التحقق أو Cookies.
- لا تُرسل كراسة الشروط أو جدول الكميات أو أي ملف أو مرفق.
- لا توجد عقد GPT أو Qwen أو Grok أو Ollama في هذه المرحلة.
- البيانات المنقولة هي: الرقم المرجعي، العنوان، الجهة، المنطقة، قيمة الكراسة، المواعيد، الحالة، النشاط ورابط التفاصيل فقط.

## التشغيل المحلي

ملف Workflow القابل للاستيراد هو `radar-phase-1.workflow.json`.

يستقبل البيانات على المسار المحلي:

`http://127.0.0.1:5678/webhook/radar-sync-5d354757-90d1-4dc3-b7f7-c93e4c50ecb1`

بعد استيراد Workflow يجب نشره أو تفعيله من n8n. زر «اختبار ربط n8n» داخل الرادار يرسل اختبار اتصال فقط ولا يحفظ بيانات الاختبار.

## المرحلة التالية

يمكن لاحقًا إضافة Ollama وQwen المحلي بعد عقدة إزالة التكرار، بحيث لا يُحلل إلا الجديد والمتغير. لا ينبغي إدخال نموذج الذكاء الاصطناعي في مسار تسجيل الدخول أو شراء الكراسة أو تنزيلها.
