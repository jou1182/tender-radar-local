# analysis-fixtures — مستندات اختبارية مصطنعة (P4-A0)

ملفات صغيرة **مصطنعة بالكامل وغير حساسة**، بمحتوى عربي تدريبي افتراضي، تُولَّد حتميًا من
`tests/helpers/analysis-fixture-factory.mjs` (نفس المخرجات في كل توليد).

| الملف | النوع | المحتوى |
|---|---|---|
| `booklet-sample.pdf` | PDF | كراسة شروط تدريبية — 3 صفحات (ضمانات، مواعيد، غرامة، بند غير واضح، سؤال للجهة) |
| `boq-sample.xlsx` | XLSX | جدول كميات تدريبي — ورقتان (بنود وكميات + ملاحظات) |
| `conditions-sample.docx` | DOCX | شروط عامة تدريبية — عنوانان وفقرات وجدول |

- لا توجد هنا أي بيانات حقيقية من منصة اعتماد أو غيرها.
- محرك التحليل لا يقبل إلا هذه الملفات عبر `fixtureId` الموثق في `scripts/lib/analysis-fixtures.mjs`.
- لإعادة التوليد: استخدم `buildFixtureBuffers()` من مصنع الاختبارات (للاختبارات والمراجعة فقط).
