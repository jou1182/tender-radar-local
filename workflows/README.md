# workflows — مهام n8n القابلة للاستيراد (غير مفعّلة)

## p4a-local-analysis.json — تحليل المستندات المحلي (P4-A0)

مهمة مستقبلية **غير مفعّلة** (`"active": false`) تربط n8n المحلي بمحرك تحليل المستندات المحلي عبر API الرادار فقط.

### التدفق

1. **استقبال analysisJobId** — Webhook يستقبل POST بجسم `{ "analysisJobId": "..." }` فقط.
2. **التحقق من المدخل** — يرفض أي طلب بلا `analysisJobId`.
3. **تشغيل مهمة التحليل محليًا** — HTTP Request إلى `http://127.0.0.1:4318/analysis/jobs/{id}/run` (localhost حصرًا).
4. **تسجيل النجاح / الفشل** — رد JSON بالحالة فقط.

### الضمانات

- لا credentials ولا كلمات مرور ولا tokens في الملف.
- لا عقد ذكاء اصطناعي سحابية.
- لا إرسال ملفات — يُرسل معرف المهمة فقط.
- لا اتصال باعتماد ولا مزامنة ولا تنزيل.
- الاتصال الوحيد: `127.0.0.1:4318` (خدمة الرادار المحلية).

### طريقة الاستيراد لاحقًا (لا تستورده الآن)

1. شغّل خدمة الرادار المحلية (`npm run sync-service` من جذر المشروع).
2. أنشئ مهمة تحليل عبر `POST /analysis/jobs` بـ`fixtureId` من `GET /analysis/health`.
3. في n8n المحلي: **Workflows → Import from File** واختر هذا الملف.
4. راجع أن العقدة الوحيدة الخارجية هي HTTP Request إلى `127.0.0.1:4318`، ثم فعّل الـworkflow يدويًا عند الحاجة فقط.
