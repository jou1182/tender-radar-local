# REVIEW_CHECKLIST — قائمة مراجعة المشرف

> يراجع المشرف كل تسليم قبل الاعتماد. **المنفذ لا يعتمد عمله بنفسه إطلاقًا.**

## الهوية والنطاق

- [ ] الـcommit الأساس في التقرير يطابق الأساس المطلوب في المهمة.
- [ ] اسم الفرع ومسار worktree يطابقان المهمة، والفرع مبني مباشرة على الأساس.
- [ ] عدد الـcommits فوق الأساس يطابق المهمة (واحد غالبًا): `git rev-list --count <base>..<branch>`.
- [ ] كل ملف معدّل/مُنشأ ضمن قائمة «المسموح» فقط — لا ملف خارج النطاق.

## مراجعة الـdiff الفعلي

- [ ] قراءة `git diff <base>..<branch>` **الفعلي كاملًا** — لا الاكتفاء بالتقرير.
- [ ] لا إضعاف لأي حاجز أمان أو مدقق أو grounding أو بوابة موافقة.
- [ ] لا secrets: لا مفاتيح API ولا tokens ولا cookies ولا كلمات مرور ولا مفاتيح خاصة.
- [ ] لا مسارات مستخدم مطلقة ولا أسماء مستخدمين في الملفات المُسلَّمة.
- [ ] لا dependency جديدة ولا تعديل لـpackage-lock.json ما لم تنص المهمة.

## الجودة الآلية

- [ ] `npm test` كاملة ناجحة بالعدد المعلن — وأُعيد تشغيلها عند المشرف عند الشك.
- [ ] `npm run build` ناجح.
- [ ] `npm run lint` نظيف بلا أخطاء ولا تحذيرات.
- [ ] `npm run db:init` ناجح و`schemaVersion` لم تتغير دون مهمة migration صريحة.
- [ ] `git diff --check` نظيف و`git status --porcelain` فارغ.

## الحدود الحية

- [ ] لا اتصالات شبكة ولا إجراءات حية غير مصرح بها في الـdiff أو في سجل التنفيذ.
- [ ] لا تشغيل لـOllama/n8n/Docker/Chrome/اعتماد خارج تصريح المهمة.
- [ ] لا مزامنة أو تنزيل أو شراء أو استهلاك موافقة.

## قاعدة البيانات

- [ ] قاعدة التشغيل لم تُفتح ولم تُعدَّل خارج مسار التطبيق.
- [ ] **نسخة احتياطية من SQLite قبل أي migration أو تغيير بيانات** (انظر OPERATIONS_RUNBOOK.md).

## الدمج

- [ ] الدمج — عند اعتماده — **fast-forward only** وبمهمة دمج منفصلة:
  `git merge --ff-only <commit>` بعد التحقق من السلسلة والنظافة.
- [ ] لا merge commit ولا rebase ولا cherry-pick ولا force أي شيء.

## التقرير

- [ ] التقرير خارج Git، ويحمل: الفرع، الأساس، الـcommit الجديد، الملفات، أعداد الاختبارات
      الدقيقة، نتائج build/lint/db:init، وتأكيدي عدم الدمج وعدم الإجراء الحي.
- [ ] أي ملاحظة أو تعارض سجّلها المنفذ عولجت قبل الاعتماد — لا اعتماد مع سؤال مفتوح.
