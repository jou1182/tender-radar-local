## تعليمات الاستعادة والتحقق

1. انسخ مجلد الحزمة كاملًا إلى مكان العمل الجديد، ولا تفتح أي ملف منه قبل التحقق.
2. من جذر المستودع المستعاد (أو أي مستودع يحتوي أدوات التحقق)، نفّذ أمر التحقق الواحد:
   `npm run recovery:verify -- "<RECOVERY_BUNDLE_DIR>"`
   ولا تتابع إلا بنجاحه (exit code صفر).
3. استعد المستودع من الحزمة: `git clone repo.bundle "<TARGET_DIR>"` ثم تحقق أن
   HEAD المستعاد يساوي الرأس المسجل أعلاه.
4. النسخة المتسقة من قاعدة البيانات هي `database.sqlite` داخل الحزمة؛ انسخها إلى
   موضع البيانات المحلي للمشروع بعد نجاح التحقق فقط.
5. راجع [دليل حزمة التعافي](docs/RECOVERY_BUNDLE.md) ثم سلّم الأدوار عبر
   [رسالة المنفّذ البديل](docs/REPLACEMENT_EXECUTOR_PROMPT.md) و
   [رسالة المشرف البديل](docs/REPLACEMENT_SUPERVISOR_PROMPT.md).

## قواعد حاكمة بعد الاستعادة

- مصدر الحقيقة هو Git وSQLite والاختبارات، لا أي سجل محادثة سابق.
- لا تفترض وجود أي وكيل أو مزود بعينه؛ الأدوار EXECUTOR وSUPERVISOR هي الحاكمة.
- لا تستأنف أي بوابة متوقفة إلا بمهمة مكتوبة جديدة بعد تحقق الحالة قراءةً.
- لا تشغيل لأي خدمة حية (متصفح، منصة، نماذج محلية، أتمتة) دون موافقة صريحة جديدة.
