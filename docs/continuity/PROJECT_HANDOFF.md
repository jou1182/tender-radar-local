# PROJECT_HANDOFF — تسليم مشروع رادار المنافسات

> اقرأ هذا الملف مع بقية ملفات الحزمة قبل أي عمل. مصدر الحقيقة هو Git وSQLite والاختبارات.

## الهدف التجاري

متابعة منافسات منصة اعتماد السعودية في قطاع المقاولات (وبعد استقرار النسخة اليومية: أنشطة
أساسية وفرعية أوسع)، مع رصد يومي للمنافسات الجديدة والمتغيرة، وقراءة تفاصيلها، وتحليل
كراسات الشروط محليًا لدعم قرار الدخول المبدئي — كل ذلك على جهاز المالك دون خدمات سحابية.

## ما الذي يقدمه المشروع حاليًا

- واجهة محلية (`http://localhost:3000`) تعرض المنافسات من SQLite المحلية.
- خدمة مزامنة محلية (منفذ 4318) تقرأ قوائم اعتماد عبر جلسة Chrome بشرية، مع نقاط استئناف.
- التقاط تفاصيل صفحة المنافسة المرئية، بما فيها قيمة الكراسة من صفحة التفاصيل الموثوقة.
- ملفات شخصية للبحث متعددة الأنشطة (أساسية/فرعية) بحدود أمان.
- نوايا موافقة بشرية محكومة لمرفقات المنافسات (تحضير بوابة التنزيل، دون تفعيل حي).
- تحليل محلي للكراسات (PDF/XLSX/DOCX) عبر Ollama المحلي مع:
  - استخراج حتمي وتقسيم محدود الحجم.
  - كتالوج أدلة حرفية حتمي (معرفات `cand-` مشتقة بـSHA‑256).
  - النموذج يختار معرفات الأدلة فقط؛ البرنامج يبني تقرير `analysis-report-v2` canonical.
  - تحقق صيغة كلي + تطبيع معرفات بنطاق المهمة + تأسيس (grounding) صارم بلا تخفيف.
  - مزود stub حتمي هو الافتراضي؛ Ollama معطل افتراضيًا ولا يعمل إلا بتفعيل صريح.
- الاختبارات المحلية: **219 ناجحًا / 0 فاشل** عند الأساس الوظيفي الحالي (P4-M0AMRM)، و**251 ناجحًا / 0 فاشل** بعد إكمال حزمة الاستمرارية وإغلاق P4-H1B. التفاصيل الآلية في CURRENT_STATE.json تحت `testBaselines`. حزمة التعافي الذاتية أصبحت جاهزة ومختبرة ومكتملة تمامًا، ولا تعتمد استعادة المشروع على أي مزود ذكاء بعينه أو سجل محادثة سابق، حيث تحتوي الحزمة على Git bundle للمستودع، ونسخة SQLite متسقة، ورسائل البدلاء المحايدة، وأداة تحقق مستقلة بذاتها.

## حدود التكامل مع منصة اعتماد

- القراءة فقط عبر جلسة Chrome البشرية للمالك؛ لا API رسمي ولا تجاوز حماية.
- تسجيل الدخول وCAPTCHA وCloudflare يكملها الإنسان وحده.
- لا شراء ولا دفع ولا انضمام ولا تقديم عرض — اليوم وفي أي مرحلة لاحقة دون بوابة بشرية جديدة.
- التنزيل الحي لم يُفعَّل؛ بوابة الموافقة والمحوّل المحكوم جاهزان ككود مختبَر بالمحاكاة فقط.

## ما تم إنجازه (P0 → P4-M0AMRM)

السجل المختصر بالـcommits في [PHASE_LEDGER.md](PHASE_LEDGER.md). الخلاصة:

1. أساس المشروع والواجهة (P0).
2. قاعدة SQLite الإنتاجية ومزامنة قابلة للاستئناف (P1) واختباراتها السلوكية.
3. التقاط تفاصيل المنافسة المرئية وجودتها (P2).
4. ملفات بحث متعددة الأنشطة آمنة (P3‑A).
5. نوايا موافقة المرفقات (P3‑B0)، ومحوّل تنزيل محكوم معطل افتراضيًا (P3‑B1A)،
   ونزاهة قيمة الكراسة صفر من صفحة التفاصيل (P3‑B1B0)، وفحص P3‑B1B الحي للقراءة فقط
   الذي انتهى **بتوقف آمن معتمد (approved_safe_stop)**: لم يُعثر على منافسة تؤكد صفحة
   تفاصيلها الموثوقة السعر صفر، فلم يُفحص اسم ملف ولا عنصر تنزيل، ولم تُطلب أو تُستهلك
   موافقة، ولم يُنزَّل أي ملف — وهو ليس نجاحًا وظيفيًا كاملًا.
6. أساس التحليل المحلي الكامل (P4‑A0 وتشديداته A0R/A0R2).
7. تقوية المدقق الكلي (P4‑A1R)، وفرض JSON Schema عبر `format` (P4‑A1C0)،
   كتالوج الأدلة بالمعرف فقط (P4‑A1D0)، ودمجه المعتمد (P4‑A1D0M)، وتصميم مقارنة النموذجين (P4-M0A) ودمجه المعتمد (P4-M0AMRM).

## ما لم يُنجز بعد

- التنزيل الحي الفعلي لأي ملف (P3‑B1C ما زالت متوقفة).
- اكتملت خارطة v1 بالكامل (P4-REL2) ووُسِم `v1.0.1-local` — التفاصيل في [NEXT_PHASES.md](NEXT_PHASES.md) و[PHASE_LEDGER.md](PHASE_LEDGER.md).
- المرحلة التالية المخطط لها: **P4‑O0** (تقوية التشغيل اليومي).
- أي تجربة على مستند حقيقي — تحتاج موافقة مكتوبة من المشرف (SUPERVISOR) وتكليف صريح للمنفذ (EXECUTOR).

التفاصيل والترتيب في [NEXT_PHASES.md](NEXT_PHASES.md).

## مستويات البيانات — لا تخلط بينها

| المستوى | المصدر | الثقة |
|---|---|---|
| بيانات القائمة | صفحات نتائج اعتماد | أولية — قابلة للتقادم |
| بيانات صفحة التفاصيل | صفحة المنافسة نفسها | **الموثوقة** — منها قيمة الكراسة |
| أسماء المرفقات | metadata من صفحة التفاصيل | أسماء فقط — ليست ملفات |
| الملفات المنزلة | binary عبر بوابة الموافقة | لا وجود لها حاليًا — التنزيل متوقف |
| نتائج التحليل | التحليل المحلي على fixtures | مجرّبة على fixtures فقط |

## حقائق تشغيلية حاكمة

- **المجانية لا تُثبت إلا من صفحة التفاصيل**: لا يُعتمد مرشح بحث ولا بطاقة ولا سجل SQLite
  قديم لإثبات أن المنافسة مجانية؛ السعر صفر يُقرأ من صفحة التفاصيل الموثوقة فقط.
- **P3‑B1B بحالة approved_safe_stop**: نُفذ فحص حي للقراءة فقط وانتهى بتوقف آمن لعدم
  العثور على منافسة مجانية مؤكدة من صفحة التفاصيل؛ إعادته معلقة حتى ظهور منافسة تؤكد
  صفحة تفاصيلها أن قيمة الكراسة صفر.
- **P3‑B1C متوقفة (paused)**: لا تنزيل حيًا ولا استهلاك موافقة دون مهمة جديدة معتمدة
  وموافقة بشرية جديدة.
- **التحليل المحلي اختُبر على fixtures فقط**؛ لم يُجرَّب على مستند حقيقي.
- الجلسة الحية الوحيدة المسموحة هي جلسة Chrome البشرية للمالك، وتُدار وفق
  [SAFETY_BOUNDARIES.md](SAFETY_BOUNDARIES.md).
